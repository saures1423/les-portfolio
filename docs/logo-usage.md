# Leslie Sabornido Logo

## Primary Direction: Open Frame

The selected mark combines an `L` foundation with a flowing `S`. Open corner accents reference interface frames and the connection between front-end craft and back-end systems. Its square proportions keep it clear in navigation, favicons, and profile images.

## Files

-   `public/brand/leslie-sabornido-mark.svg`: primary icon for dark backgrounds
-   `public/brand/leslie-sabornido-logo-horizontal.svg`: icon and wordmark lockup
-   `public/brand/leslie-sabornido-mark-monochrome.svg`: single-color version
-   `public/brand/leslie-sabornido-logo-preview.svg`: presentation preview on the brand background
-   `public/brand/concepts/leslie-sabornido-concept-stack.svg`: alternate stacked-system concept
-   `public/brand/concepts/leslie-sabornido-concept-path.svg`: alternate connected-product concept

## Colors

-   Lime: `#D1F463`
-   Coral: `#FF8F70`
-   Off-white: `#F3F7F4`
-   Deep background: `#071316`

## Usage

-   Use the primary mark on dark, quiet backgrounds.
-   Use the horizontal lockup when at least 220 px of width is available.
-   Use the monochrome mark when only one ink or color is available.
-   Keep clear space around the mark equal to roughly one quarter of its width.
-   Do not stretch, rotate, add effects, or recolor individual strokes.
-   Minimum recommended digital size: 28 px for the mark and 180 px for the horizontal lockup.
